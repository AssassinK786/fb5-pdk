# 105-lot WAT statistics (passives_stats.txt, column alignment in that file is
# unreliable - treat as rough): Contact Resistance POLY median 60.9,
# POLY2 median 16.8, MTL2 16.25, MTL3 25.8, UNITS 0.905.
#
# ---------------------------------------------------------------------------
# IMPORTANT: WAT fringe != magic perimc
# ---------------------------------------------------------------------------
# magic SCN3ME_SUBM.30.tech encodes perimc (m1)=22.200 aF/lambda, which is
#   22.200 / 0.30 = 74 aF/um, whereas the WAT Fringe (substrate) M1 is 52 aF/um.
# Same for M2: magic 17.400/0.30 = 58 vs WAT 33; M3: 11.400/0.30 = 38 vs WAT 26.
# magic folds both edges / sidewall coupling into one perimc coefficient, so it
# is systematically larger than the single-sided WAT fringe.  fb5_wet.tsv's
# ami_c5 column is in MAGIC-RULE units (so the generator can scale them), NOT
# raw WAT units; this file records the raw WAT numbers separately.
