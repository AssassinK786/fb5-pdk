## 2. Using the models (ngspice)
```
* all paths below are relative to the PDK root (run ngspice from there)
.lib "./models/fb5.lib" tt                         * or ff ss fs sf
.include ./models/fb5_hbt.lib                     * fb5npn_hp, fb5npn_hb (area factor = parallel emitters)
.lib "./passives/fb5_passives.lib" devices
.lib "./passives/fb5_passives.lib" res_typ        * or res_low / res_high
M1 d g s b fb5n W=10u L=0.5u
Q1 c b e fb5npn_hp
X1 a b rp w=2 l=20 ; X2 t b cmim w=20 l=20
```
Keep VCE below BVceo (3.3 V hp, 5.5 V hb): Gummel-Poon does not model breakdown or self-heating.
## 2a. VBIC HBT models (optional, models/fb5_hbt_vbic.lib)
ngspice VBIC (BJT level=4) versions fb5npn_hp_v / fb5npn_hb_v, mapped from the GP cards by models/fit_vbic.py (results fit_vbic.txt).
Adds what GP lacks: avalanche (AVC1=2, AVC2 13.9 hp / 21.7 hb -> simulated BVceo 3.28 / 5.48 V), self-heating (RTH 3000 / 3500 K/W,
CTH 1 nF: ESTIMATE), quasi-saturation split RCX/RCI and RBX/RBI (ESTIMATE 0.3/0.7), small substrate PNP (ISP 1e-19, WSP 1: ESTIMATE).
TF retuned (2.45 / 3.78 ps) so peak fT stays 47.0 / 28.0 GHz; beta ~100 at 1 mA. RBX/RBI = 0.3/0.7 of GP RB
(37.2/86.8 ohm hp, 28.8/67.2 ohm hb). Extracted fMAX 60.4 / 51.9 GHz (Mason U), see validation/val_fmax.txt.
```
.include ./models/fb5_hbt_vbic.lib
Q1 c b e 0 dt1 fb5npn_hp_v      * nodes c b e substrate thermal; give every device its own dt node
```
Use VBIC when VCE can approach BVceo or for power/thermal checks; the GP models (fb5_hbt.lib) remain the default and are
faster. ECL ring (validation/val_vbic.py): VBIC 19.0-9.9 ps/gate vs GP 18.7-10.4 (Iee 0.3-1.5 mA; td=1n startup guard).
## 3. Layout
Layers: MOSIS SCMOS numbering (klayout/layers.txt) + pbase 58 (NPN base) + FB5 MIM marker 88. Rules: MOSIS SCMOS rev 7.2,
lambda 0.30 um, including the NPN analog option (rules 16.1-16.11) in klayout/fb5.drc. LVS (klayout/fb5.lvs) extracts fb5n/fb5p
and fb5npn_hp. PCells (klayout/pcells/fb5_pcells.py, library "FB5"): nmos, pmos (taps), rpoly, cpoly, gring, npn (ne emitters).
The public-rule NPN is larger than IBM's (drawn emitter 2.4 x 2.4 um) - electrical model stays per IBM 0.5 x 2.5 um device.
## 4. Digital
OSU 0.5 um cells re-characterized with FB5 CMOS: tt 3.3 V (ff 3.6 V, ss 3.0 V when present) in digital/lib.
`digital/lef/` provides `fb5_tech.lef`, `fb5_stdcell.lef` (40 MACROs), `fb5_lef.map` and `check_lef.py`
(run with `klayout -b -r`). The characterization script and a full DEF/LEF place-and-route flow are NOT
bundled (see ESTIMATES.md); liberty, GDS, SPICE, Verilog and LEF views are provided.

## 4a. Parasitic extraction and post-layout simulation
`validation/parasitics/` runs magic 8.3 `extract` + `extresist` + `ext2spice` with the public
`SCN3ME_SUBM.30.5hp.tech` (generated by `fb5_5hp_rc.py` from the vendored qflow tech,
with IBM 5HP measured/derived R/C + PROXY fringe/contact — see
`validation/parasitics/RC_SOURCES.md` and `wet_tables/`) to produce
`netlists/<CELL>.sp` subckts containing W/L, AS/AD/PS/PD, wire R and coupling/substrate C
for all 32 laid-out stdcells (353 MOSFETs, ~760 wire R, ~1100 C, sum(C) 1125.9 fF;
element counts vary +/-1 between magic runs).
`postlayout.py` compares 3-stage chains pre/post-layout (INVX1 70.3 -> 104.9 ps,
+49 %); `chain.py` extracts a placed-and-routed 3-inverter block and adds interconnect C
(210.8 -> 312.6 -> 321.1 ps). Run `make check-parasitics`.
## 5. Validation (validation/README.md)
HBT beta ~98 / peak fT 46.7 GHz / fMAX 63.9 GHz vs IBM ~100 / 47-50 GHz / 65 GHz; CMOS inv 70 / NAND2 130 ps vs IBM 90 ps;
ECL ring 10-19 ps vs IBM 16 ps. fT/fMAX are EXTRACTED (validation/val_fmax.py): fT = |h21|=1 crossing,
fMAX = Mason unilateral-gain U=1 crossing from two-port Y parameters; U(Y) is cross-checked against U(Z=invY).
Both are strongly bias-dependent (VCE 1.0 -> 3.0 V moves fMAX 57 -> 70 GHz), so quote the bias with the number.
## 6. Known gaps
Measured S-parameters / noise / thermal data for the HBT (the cards are fitted to published fT/fMAX/BVceo/beta only);
HBT current density (unit device peaks at ~1 mA, IBM 5HP minimum-area device peaks at 0.6 mA); measured HBT mismatch
(borrowed from National BiCMOS8); scalable/statistical HBT corners and temperature models; IBM's real layout rules /
NPN geometry; antenna, density, ESD, reliability rules; I/O cells; a full DEF/LEF P&R flow;
HBT/passives extraction decks; chip-level routing R (magic `extresist` only emits C at the top level).
VBIC avalanche/self-heating/substrate-PNP parameters remain ESTIMATES, not measurements.

## HBT mismatch (models/fb5_hbt_mm.lib)
sigma(dIc/Ic) = 4 %.um / sqrt(AE[um^2]), measured on National BiCMOS8 SiGe (0.4 um emitter) by M. M. Pratapgarhwala, MS thesis,
Georgia Tech, 2005 (n = 15 pairs, ideal region, 300 K). Applied as an IS/area shift in subckts npn_hp_mm / npn_hb_mm
(params ae, nsig, a_mm). Checked: AE = 4 um^2, +1 sigma gives dIc/Ic = 2.00 %. A 1 um^2 pair gives about 4 %; keep AE >= 2 um^2 (0.4x1.4 um^2 pairs showed extra gradient offset).
Borrowed from another process, not measured on IBM 5HP.

## Spiral inductor check (passives/inductor/fb5_spiral.py)
Run with the paper's stack against Ronkainen et al., IEE Proc. G 1997 (0.8 um BiCMOS, 1 um Al, 1.2 um oxide, 40-70 ohm.cm substrate):
L1 (rectangular, 6 turns, W15/S3, 285 um outer): paper L 6.68 nH, Q <= 4 at 2 GHz; model 7.32 nH (+10 %), Qmax 3.2.
4 um oxide + 4 um Al, 3 turns: model Qmax 8.3. The paper's best Q of 16 combines thick oxide and thick metal; this model's substrate values are estimates, so treat its Q as a lower bound.
With the paper's measured 35 mohm/sq metal, the unfitted model gives Qmax 2.76 at 1.1 GHz. 2026-11-05 fit (fit_ronkainen.py / fit_ronkainen.txt) to the paper's Table 2 subckt: Q within ~5 % over 0.1-6 GHz with kR 4.85 (series loss 43.6 vs 10 ohm DC), kC 0.34, negligible substrate shunt (the subckt has none). Substrate defaults kept; kR is a knob for a pessimistic corner.
